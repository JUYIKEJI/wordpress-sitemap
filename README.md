# 阿彦网站地图（WordPress 版）

给 WordPress 博客生成网站地图的插件。启用后，打开 `网站地址/sitemap.xml` 就能看到整站地图，方便搜索引擎抓取和收录。

> ⚠️ 只适用于 WordPress，不适用于 Typecho
>
> Typecho 请用另一个仓库里的 [sitemap 插件](https://github.com/JUYIKEJI/sitemap)（1.2.0 版），不要把这个装到 Typecho 上。

## 地图里有什么

| 内容 | 权重 | 更新频率 |
| --- | --- | --- |
| 首页 | 1.0 | 每天 |
| 已发布页面 | 0.8 | 每周 |
| 已发布文章 | 0.5 | 每月 |

只收录已发布的内容，草稿和未到发布时间的文章不会出现。找不到链接的直接跳过，同一个链接只出现一次，链接里的特殊符号做了转义。

## 安装

1. 把 `ayan-sitemap` 文件夹放到网站目录下的 `wp-content/plugins/`
2. 在 WordPress 后台，插件，启用“阿彦网站地图”
3. 打开 `网站地址/sitemap.xml`，确认能正常显示

## 常见问题

**打不开 sitemap.xml 怎么办？**

先确认插件已启用，再去后台“设置 - 固定链接”里点一次保存（这一步会刷新访问规则），然后再打开 `网站地址/sitemap.xml`。

**地图里为什么没有草稿？**

这是特意这样做的，只有已发布的内容才会被搜索引擎抓到。

**能用在 Typecho 上吗？**

不能，见顶部提示。
